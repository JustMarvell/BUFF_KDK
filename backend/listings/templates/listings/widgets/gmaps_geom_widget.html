{% if mode == "road" %}

Click "Add point" then click the map for a single-spot issue (e.g. one pothole). Click "Draw line" then click the map to add each point of a road stretch, then click "Finish line" when done - do this more than once to add a branch. Drag a point on a finished line to adjust it; double-click a line, or click a marker, to delete it.

{% elif mode == "single_line" %}

Click "Draw line", then click the map to add each point tracing this road stretch, then click "Finish line" when done. It doesn't need to be perfectly straight, just follow the real road - its start and end points automatically snap to the two nodes you selected above. Drawing a new line replaces the current one.

{% else %}

Click the map (or search above) to place the marker. Drag it to fine-tune the position.

{% endif %}
